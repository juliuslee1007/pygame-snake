# Snake v2

`snake_v2`는 `Pygame`으로 만든 뱀 게임입니다. 뱀을 조작해 먹이를 먹고 점수를 올리며, 게임이 끝나면 닉네임을 입력해 점수를 저장할 수 있습니다.

## 프로그램 기능

- 방향키로 뱀을 조작합니다.
- 먹이를 먹으면 뱀이 길어지고 점수가 1점씩 증가합니다.
- 벽이나 자기 몸에 충돌하면 게임 오버가 됩니다.
- 게임 오버 후 닉네임을 입력해 점수를 저장할 수 있습니다.
- `Supabase`를 이용해 점수를 저장하고 상위 점수를 조회할 수 있도록 구성했습니다.
- 화면 크기, 색상, 기본 속도는 `settings.py`에서 관리합니다.

## 사용 기술

- `Python`
- `pygame`
  - 게임 루프, 입력 처리, 화면 렌더링
- `supabase`
  - 점수 저장 및 조회
- `python-dotenv`
  - `.env` 파일에서 `SUPABASE_URL`, `SUPABASE_ANON_KEY` 로드

## 화면 흐름

1. 게임 시작
   - `main.py`에서 초기 상태를 만들고 게임 루프를 실행합니다.
2. 플레이 화면
   - 뱀, 먹이, 점수를 표시합니다.
   - 방향키로 이동 방향을 바꿉니다.
   - 먹이를 먹으면 점수가 올라가고 뱀이 길어집니다.
3. 충돌 처리
   - 벽 충돌 또는 자기 몸 충돌이 발생하면 `NAME` 상태로 이동합니다.
4. 닉네임 입력 화면
   - 닉네임을 입력한 뒤 `ENTER`를 누르면 점수가 저장됩니다.
   - `ESC`를 누르면 저장 없이 다음 단계로 넘어갑니다.
5. 재시작
   - `SPACE`를 누르면 새 게임을 시작합니다.

## 주요 파일

- `main.py` - 게임 실행 진입점, 상태 전환, 입력 처리
- `game_logic.py` - 뱀 이동, 먹이 생성, 충돌 판정
- `renderer.py` - 게임 화면과 텍스트 렌더링
- `leaderboard.py` - Supabase 점수 저장 및 조회
- `settings.py` - 화면 크기, 색상, FPS 설정

## 참고

- 현재 코드는 점수 저장과 조회 기능을 포함하고 있습니다.
- 랭킹 화면은 상태 전환용 로직이 준비되어 있으며, 필요하면 이후에 화면 표시를 더 확장할 수 있습니다.
